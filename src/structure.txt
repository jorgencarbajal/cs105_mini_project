Where things go

- Data Cleaning (code): load the csv, keep only the columns we use, fix the curly apostrophe,
  handle missing values, and do all recoding (answer groupings, 0-3 scales, AI-reliance score).
  The PDF says to "create your own dataset (remove all columns that you won't need, clean the
  data that you plan to analyze)", so this happens once, up front.
- Each Viz code cell: only the computations for that chart (crosstabs, percentages, medians) + the plot.
- Each Hypothesis code cell: only the statistical test.

Example:

jcarb044
- Data Cleaning: AI-reliance score, reason groups (violin), CU/BU groupings (mosaic), apostrophe fix
- Viz 1: violin plot
- Viz 4: mosaic plot (crosstab + percentages)
- Hypotheses: chi-squared (mosaic)
